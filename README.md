## Scope of This Repository

This repository contains **historical laboratory-level prototypes**
derived from the ICARUS closed-cycle homeostatic architecture.

The code is:
- experimental
- non-production
- intended exclusively for technical analysis of internal dynamics,
  stability, and control mechanisms

This repository **does not define**, **extend**, or **modify** the ICARUS framework.
